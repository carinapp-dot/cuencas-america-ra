# Misión: Cuencas de América

Experiencia interactiva educativa sobre cinco grandes sistemas hidrográficos de América.

## Uso
Abrí `index.html` o publicá el repositorio con GitHub Pages.

Incluye:
- mapa interactivo adaptado a celular;
- cinco estaciones con explicación y narración mediante la voz del dispositivo;
- sistema de cinco gotas;
- desafío final de 10 preguntas;
- progreso guardado en el navegador.

La imagen base está en `assets/cuencas-america.png`.
